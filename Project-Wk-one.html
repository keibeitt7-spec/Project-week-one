#Project Overview

In this project, I will use R to perform a basic data science workflow on a customer transaction dataset. The project introduces the use of R for data import, data inspection, data cleaning, exploratory data analysis (EDA), visualization, and interpretation.

The dataset contains transaction-level information including customer demographics, product characteristics, payment methods, transaction dates, prices, quantities, ratings, and membership status. The dataset Variables include:TransactionID,CustomerID,ProductID,Quantity,PaymentMethod,TransactionDate,ProductCategory,Price,Rating,TotalAmount,Age,Gender,Location, and MembershipStatus.
